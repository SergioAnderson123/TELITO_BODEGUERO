# Telito Bodeguero 🛒

> Sistema web de gestión para bodegas, con backend Java Spring Boot
> y frontend HTML/CSS. Desarrollado como proyecto universitario en PUCP.

## 📋 Descripción

Aplicación web para la gestión de inventario y ventas de pequeñas bodegas.
Permite registrar productos, ventas y generar reportes básicos.
Desarrollado con arquitectura MVC usando Spring Boot y Thymeleaf.

## ✨ Funcionalidades

- ✅ Gestión de inventario de productos
- ✅ Registro de ventas y transacciones
- ✅ Panel de administración web
- ✅ Arquitectura MVC con Spring Boot

## 🛠️ Stack utilizado

| Capa | Tecnología |
|------|-----------|
| Backend | Java, Spring Boot, Maven |
| Frontend | HTML, CSS, Thymeleaf |
| Servidor | Apache Tomcat |

## 🚀 Cómo ejecutar

```bash
# Clonar el repositorio
git clone https://github.com/SergioAnderson123/TELITO_BODEGUERO.git

# Entrar al directorio
cd TELITO_BODEGUERO

# Ejecutar con Maven
./mvnw spring-boot:run
```
